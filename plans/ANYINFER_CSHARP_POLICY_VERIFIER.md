- Profile is exactly request-policy-v1. Validate both closed schemas and all cross-record
  references, input procedures and output qualification. Top-level observations are actual
  experiments with nested operation outcomes; identical unsupported/harness errors fail.
- No mutable profile registry, broad error superclass matcher, value normalizer, policy
  calculator, expected-output table, or case-ID dispatch. Literal runtime error pairs and
  ordered fields stay profile-local. Preserve bool/number, null/zero, list order, exact
  money/raw-argument strings and typed values. Object field ordering follows the frozen
  contract; resource comparison accepts only its declared causal partial orders.
- Qualification is selected from input kind/procedure. Require exact ledger checkpoints,
  operation/trail/script correspondence, actual primary seam records, typed tool/privacy/
  cache/config/header facts and declared resource joins. A wrapper wire plus its HTTP
  handler is one dispatch. Never infer private semaphore readiness or delay/wait counts.
- Standard execution creates a fresh run directory, captures source identity before
  execution, builds AnyInfer.RequestPolicy/AnyInfer.RequestPolicy.csproj with --no-restore,
  SourceRevisionId and RequestPolicySourceDirty, then independently runs Python and native
  observers. Compare mode copies supplied files byte-for-byte into another fresh run.
  Use existing accounting CLI conventions for input/output-root/compare options unless the
  frozen policy contract specifically differs. Reports retain raw mismatches/provenance.
- Native-only timer/ownership/range mechanics remain native unit/accounting exclusions;
  do not turn fixture echoes into observed controls or inflate shared-match counts.
